RECOMMENDATIONS
======================================================================

1. COVERAGE GAP (most critical):
   36 of 96 ground-truth compounds (38%) have NO library
   match returned by this task. Possible causes:
   - Low topK setting: increase to 50-100 hits per query.
   - Strict mz-tolerance: loosen the search window.
   - Missing reference spectra in the libraries searched.

2. HIGH-CONFIDENCE WRONG PREDICTIONS (7 scans, score >= 55):
   These are the most harmful errors. Root causes observed:
   - scan 1564: GDP-glucose returned for GDP-mannose (structural
     isomers). The WCRS/Tanimoto can't distinguish them if SMILES are
     missing or library conflates mannose/glucose annotations.
   - scan 852: Furoic acid returned for Cysteate — likely a
     cosine false positive at similar precursor mass. Adding a precursor
     m/z exact-match gate or stricter PPM filter would help.

3. NAME CLEANING ISSUES IN LIBRARY ANNOTATIONS:
   The following name patterns are NOT cleaned by _clean_compound_name
   and pollute top_compound, causing incorrect-looking outputs:
   - 'CollisionEnergy:102040' suffix (only 'N eV' style is stripped)
   - Bare CAS registry numbers (e.g. '56546-36-2', '39711-79-0')
   - 'Candidate X-C2:0 (delta mass:...)' acyl-lipid annotations
   - '(known structural isomers: N; isobaric peaks in run: N)' notes
   Fix: extend _clean_compound_name with these four patterns.

4. SCORE CALIBRATION:
   Correct mean: 71.2  |  Wrong mean: 69.1

5. TANIMOTO / WCRS:
   Correct-vs-wrong Tanimoto delta: +0.045
   Tanimoto does not discriminate well between correct and wrong here.
   This is expected when wrong predictions are structural isomers or
   when SMILES are missing and tanimoto falls back to structure_agreement.
